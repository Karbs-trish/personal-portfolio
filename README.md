## ✨ Features

* **⚡ Clean & Accessible UI:** Designed with high readability, responsive layouts, and modern visual design principles.
* **🌓 Dark/Light Mode:** Includes a theme toggle using custom CSS properties stored in `localStorage` for user preference persistence.
* **📱 Fully Responsive:** Adaptive layouts optimized for mobile, tablet, desktop, and ultra-wide displays.
* **🛠️ Modular Technical Skills:** Formatted skill categories prioritizing clean competencies over arbitrary percentage metrics.
* **📬 Interactive Contact Form:** Built-in form interface ready for service integration (e.g., Formspree, EmailJS).
* **⚡ High Performance:** Zero external framework bloat—100% vanilla JavaScript and CSS variables for maximum loading speeds and accessibility.

---

## 🛠️ Tech Stack & Tools

* **Frontend:** HTML5, CSS3 (SCSS/CSS Variables), Vanilla JavaScript (ES6+)
* **Fonts & Icons:** Google Fonts (Inter, JetBrains Mono), Inline SVG Icons
* **Deployment & CI/CD:** Vercel (Auto-deploys via GitHub Integration)
